# hkm-plugin-commands

> HKM Kernel plugin — provides **`system.commands`**.
> Part of the [HKM Kernel](https://github.com/AlfaCode-Team/hkm-kernel) Gated Demand Architecture framework.

[![License: MIT](https://img.shields.io/badge/License-MIT-green)](LICENSE)
![PHP](https://img.shields.io/badge/PHP-8.4%2B-777bb4)

## Install

```bash
composer require alfacode-team/hkm-plugin-commands
# or, from a project:
hkm plugins add commands
```

## Capability

Provides `system.commands`.
